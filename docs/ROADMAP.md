## 🐛 Известные проблемы

- **Vite dev-режим vs prod-сборка** — иногда дают разное визуальное отображение из-за порядка применения CSS-правил. Если есть сомнения — проверять через `npm run preview` (prod-build локально).
- **HMR на JSON** — Vite не всегда корректно обновляет страницу при изменении импортированных JSON. Лечится hard-reload (Cmd+Shift+R).
